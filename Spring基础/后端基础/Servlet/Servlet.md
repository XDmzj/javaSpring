# Servlet是什么

**Servlet 是运行在服务器端的 Java 程序，它是连接“用户请求”与“后端代码”的桥梁。** 没有它，Java 也就失去了处理 Web 动态交互的能力。

## 1. 核心作用

在早期的互联网中，服务器只能返回静态的 HTML 页面。Servlet 的出现让服务器能够：

- **接收请求**：读取用户在浏览器输入的数据（如登录账号、搜索关键词）。
    
- **处理逻辑**：调用数据库、执行业务计算。
    
- **生成响应**：动态生成网页内容（HTML）或返回数据（JSON/XML）。
    

---

## 2. Servlet 的工作流程

当你在浏览器输入网址并回车时，幕后发生了以下过程：

1. **客户端发送请求**：浏览器发起一个 HTTP 请求。
    
2. **容器（Tomcat）接管**：Web 容器接收请求，发现是找某个 Servlet。
    
3. **创建/调用**：容器加载该 Servlet，并调用其 `service()` 方法。
    
4. **业务处理**：Servlet 处理数据，并把结果写回响应。
    
5. **返回响应**：容器将结果打包成 HTTP 响应发回给浏览器。
    

---

## 3. Servlet 的生命周期

Servlet 不由开发者手动 `new` 出来，而是由 **Servlet 容器**（如 Tomcat）管理的。它的生命周期包含三个关键阶段：

|**阶段**|**方法**|**说明**|
|---|---|---|
|**初始化**|`init()`|Servlet 第一次被访问时执行，仅执行一次。|
|**服务**|`service()`|每次请求都会调用，处理核心业务。|
|**销毁**|`destroy()`|服务器关闭或 Web 应用卸载时执行，释放资源。|



# 声明Servlet

## “声明”是什么意思？

在编程中，“声明”就是**告诉系统某个东西的存在及其规则**。

对于 Servlet 来说，你写好了代码，Tomcat 并不知道这个类是用来处理 Web 请求的。你需要通过“声明”来建立**映射关系**：

- **告诉容器**：这里有一个类叫 `LoginServlet`。
    
- **设定规则**：当用户访问 `/login` 这个 URL 时，请把请求交给这个类处理。
    

**声明的方式：**

- **XML 声明**：在 `web.xml` 里写 `<servlet>` 标签（类似在名单上登记）。
    
- **注解声明**：在类名上方写 `@WebServlet("/login")`（类似给类贴个显眼的标签）。
